# 🚀 Projetos em destaque

## 🎵 Groovelish

Plataforma web desenvolvida com o objetivo de auxiliar no **aprendizado da língua inglesa através da música**.

O projeto foi desenvolvido durante minha formação técnica em Desenvolvimento de Sistemas e combina tecnologia e educação em uma experiência interativa para os usuários.

### Principais funcionalidades

* 🔐 Sistema de autenticação de usuários
* 👤 Gerenciamento de sessões
* 📊 Acompanhamento do desempenho dos usuários
* 🎵 Aprendizado de inglês através de músicas
* 🗄️ Integração entre aplicação e banco de dados

### Tecnologias utilizadas

`HTML` • `CSS` • `JavaScript` • `PHP` • `MySQL`
